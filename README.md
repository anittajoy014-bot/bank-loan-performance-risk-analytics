                                                  🏦 Bank Loan Performance & Risk Analytics

End-to-End Financial Portfolio Analysis | Python + Power BI

📌 Project Overview

This project presents a comprehensive loan portfolio performance and risk analytics solution, integrating Python-based data analysis with an interactive Power BI dashboard.

The objective was to transform raw financial loan data into strategic insights covering:

Loan demand trends

Credit exposure distribution

Portfolio risk assessment

Repayment performance

Profitability evaluation

The project simulates a real-world banking analytics environment used by credit risk and financial performance teams.

🛠 Technology Stack

Python (Pandas, NumPy, Matplotlib)

Power BI

DAX (Data Analysis Expressions)

Data Cleaning & Feature Engineering

Financial KPI Modeling
